# A-Stock Agent System 架构审查与修复报告（2026-06-22）

## 结论

Claude 的改造方向是正确的：系统已经从“多脚本打分”演进为不可变快照、运行时 DAG、
策略准入、统一 Policy、规范账本和组合级 OOS 证据链。PR #34-#37 对研究报告中的
择时、主线、龙头、拥挤/脆弱、市场状态和反事实分析做了真实实现，并且新打板策略仍
保持 research-only，没有绕过准入门禁。

但“报告四阶段已经全部落地”的表述过度。审查时仍存在会影响风险收益真实性的问题：
退潮状态默认不减仓、09:25 竞价未消费退潮上下文、反事实组合使用不同评估区间、空仓
基线计算错误、行为风险模块未进入运行时状态，以及 GitHub 没有 CI。上述代码缺口已在
本地修复。系统仍没有已部署的 Hermes/OpenClaw/系统 cron，也没有足够 point-in-time
样本证明新增策略存在样本外 alpha，因此不能把架构完成等同于可获利能力已经验证。

## 架构评价

### 数据层

完整候选发现主链以交易所股票列表和腾讯全市场批量行情为主，不依赖本次 doctor 中失败
的 Eastmoney spot，因此主链并未直接失效。当前 provider doctor 仍为 `degraded`：
Eastmoney 资金流、同花顺行业目录和 AkShare 全 A spot 失败；腾讯单票行情和 AkShare
涨停池正常。板块映射门槛目前只有 20%，不足以支撑高置信度主线识别。新增游资策略保持
research-only 是正确选择，在稳定板块映射和样本外证据齐备前不应注册。

### 信号与策略层

择时 -> 主线 -> 龙头 -> 竞价 -> 开盘 -> 09:50/13:15 的证据链已经存在，且候选携带
不可变快照引用。拥挤/脆弱、龙头消融和状态机目前都是日线代理，不具备逐笔因果识别能力；
代码已诚实标注这一边界。`wait_one_session` 只是延迟入场代理，没有重新观察确认信号，
不能称为“确认后买入”。

### Policy、账本与反馈

统一 Policy、T+1、公告/可成交性/组合风险和策略注册门禁总体完整。退潮默认降风险和
行为风险运行时投影补上了本轮最重要的治理缺口。行为风险目前只作为第二观察者暴露，尚未
经过 OOS 验证，不应直接成为正向选股因子。

### 回测与研究门禁

组合回放具备下一交易日开盘、T+1、100 股整数手、费用/滑点、封死涨停不可买和跌停无法
卖出的基本现实约束。修复后所有变体使用相同评估区间。仍然缺少分钟级回封成交、排队概率、
盘口冲击和策略真实退出规则；当前固定最短持有后收盘退出只能验证排序方向，不能证明实盘
收益。研究门禁必须继续拒绝仅靠案例或日线代理得出的盈利声明。

### GitHub 与运行态

审查起点本地 `main` 与 `origin/main` 相同，GitHub 无 open PR。远端没有 Actions workflow
和主分支保护。本机也没有 `hermes`/`openclaw` 可执行文件、系统 crontab 或 Hermes cron
输出，因此升级后的调度链并未实际运行。代码修复和 CI 文件目前只在本地工作树，尚未提交
或推送。

## 剩余优先级

1. **P0 运行闭环**：选择并安装 Hermes、OpenClaw 或系统 cron 的一个正式入口，部署
   `run_agent_dag.py`，验证实际交易日 D0/D1 artifact 连续产生。
2. **P0 远端质量门**：提交并推送本轮变更，CI 首次全绿后为 `main` 启用 required status
   check 和禁止未验收直推。
3. **P0 样本积累**：至少连续积累可审计 point-in-time 候选、竞价、开盘、09:50、13:15
   与 T+1/T+3 结果；新增打板策略继续保持未注册。
4. **P1 数据升级**：优先解决稳定板块归属、竞价/分钟成交和昨日强势股次日溢价序列，
   对应研究报告明确列出的三类最高价值数据。
5. **P1 研究升级**：用固定评估区间重新跑 OOS；分别检验主线前二、龙一/龙二、竞价、
   09:50 和 13:15 的增量，加入成本/延迟/流动性压力测试。
6. **P2 概率校准**：样本量足够后再校准 S0-S6 与三情景分布；在此之前只把它们当风险
   状态权重，不用于收益概率宣传。

“获取最大收益”不能作为可验证的工程验收项。建议使用一组同时约束收益与生存性的指标：
OOS 超额收益、最大回撤、Calmar、成交后收益、成本压力后的净收益、连续亏损、策略容量和
数据缺失率。只有这些指标在固定规则、固定区间和真实可成交假设下成立，策略才有资格从
research-only 进入 live reference。
