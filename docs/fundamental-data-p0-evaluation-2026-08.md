# 基本面取数（B3 / P0）投入评估（2026-08-07）

对应「serenity 研究平面缺位 → 用确定性筛查打地板」方案（B3）的取数阶段评估。
**结论先行：P0 取数管道挂起，不投。挂起理由是价值侧塌了，不是成本侧涨了。**
纯打分器（P1）照常合入，喂什么数据源都能用；若将来重启取数，**用 akshare，
不要走巨潮 PDF**——本文附实测证据。

---

## 1. 背景：这个评估从哪来

`serenity_refresh` 研究任务自 2026-07-31 起在 research bus 上积压：账本
`research_ledger.jsonl` 12 条事件**全是 `research.enqueued`**，零 claim、零 submit；
61 个 cron 作业没有任何一个调用 `expert_runner`（它只出现在一句散文
`external_note` 里）。后果是 `cache/deep_research/` 里 2270 个条目中 2264 个是
`.lock` 占位，仅有的 3 个 json 的 `generated_at` 全部落在 `2026-06-25T21:50:32~33`
——与 pytest 写穿生产状态目录污染 `strategy_registry` 的时间戳同一秒区间，
且 `dimensions` 均为 `{}`。**合法深研记录数为 0。**

由此 `serenity_hard_risk` 这道一票否决在几乎所有标的上是哑弹（已由 PR #177
改为 fail-closed）。B3 是「消费端运营方案（B1/B2）落地前的地板」：用确定性
筛查补上红线，而不是让风控闸空转。

## 2. 消费契约决定了方案形状

`research_evidence._serenity_evidence` 只有两个字段带一票否决权：

| 维度 | 权重 | 阈值 | 可确定性计算 |
|---|---:|---|---|
| `financial_quality` 财务质量 | 15% | ≤2 → hard risk | ✅ 财报可算 |
| `risk_control` 风险控制 | 15% | ≤2 → hard risk | ⚠️ 部分可算 |
| `valuation_odds` 估值赔率 | 20% | — | ⚠️ 分位可算，赔率需假设 |
| `industry_space` / `business_model` / `competition` | 50% | — | ❌ 判断题 |

**带否决权的两维恰好是最可计算的两维**——这是 B3 成立的前提，也是它的天花板：
确定性筛查只能给红线，给不了绿灯。

## 3. 价值侧：增量比预期小得多（三条均已核实）

1. **ST/退市股在候选发现阶段就被剔除**（`skills/common/candidate_pipeline.py:126`），
   因此 `risk_control` 的两个 severe 红旗 `st_flagged` / `delisting_risk`
   **在候选上永远不会触发**——它们筛的是根本进不了池子的股票。
2. **公告风险通道已在跑且已接入决策**：`announcement_risk.RISK_TITLE_TERMS`
   覆盖「问询/监管/风险提示/澄清/异常波动/更正」，`announcement_hard_risk`
   直接 → `avoid`。`risk_control` 里非财务的那一半是重复建设。
3. **连续两年亏损 → \*ST → 已被第 1 条过滤**，年报口径下
   `consecutive_net_loss` 基本落空，只有季报口径才有增量。

真增量只剩 3 条财务红旗：高杠杆、经营现金流持续为负、应收/商誉过重。

**决定性的一条**：按三态设计（`missing` / `screened` / `researched`），
`screened` **只启用红线否决，不恢复仓位权重**；而 trend lane 当前因
`strategy_registry` 为空 + PR #177 的 `serenity_evidence_missing`，**已经全部
是 watch**。即：

> P0 花大力气买到的，是对一条本来就买不了任何东西的车道的否决权。

## 4. 成本侧：巨潮 PDF 路线实测（华能国际 600011，2025 年年度报告）

| 环节 | 结果 |
|---|---|
| 巨潮分类码 `category_ndbg_szsh` 取年报 | ✅ 7 条，含 2025 年报（2026-03-25） |
| PDF 下载 | ✅ 2.0MB，PDF 1.7 |
| `pdf_extract`（pypdf 6.14.2） | ✅ 394k 字符纯文本，**不需要 OCR** |
| `financial_snapshot.py` 正则抽取 | ❌ **9 个指标只抽中 3 个** |

正则失败原因具体且可修：它们要求 `标签（元）数值`，而年报把单位写在表头
（`单位：元 币种：人民币`）、标签是裸的：

```
营业收入 229,288,057,955 245,550,923,498 -6.62 254,396,694,532
总资产 611,789,826,893 586,842,753,960 4.25 541,159,281,130
```

### 4.1 真正的坑：朴素表格解析会静默算错

改用「裸标签 + 同行多列数值」的表格行解析后 **6/6 全命中**，P1 打出 3/3 无红旗，
看起来完美。但负债率算出来 28.6%，对电力企业偏低。追查发现
**`负债合计` 在合并资产负债表内出现三次**（流动负债合计 / 非流动负债合计 /
负债合计），解析抓到的是第一个：

| 取值 | 负债 / 总资产 |
|---|---|
| 朴素解析（流动负债合计 174,781,263,127） | **28.6%** |
| 正确值（合并负债合计 399,271,744,759） | **65.3%** |

差 2.3 倍，**不报错、不告警**。本次两个值恰好都在 70% 阈值下方、结论未变，
但那是运气——阈值若定 60% 即翻盘。

因此巨潮路线的真正难点不是「抽不抽得到数」，而是**抽到的是不是你以为的那个数**：
合并 vs 母公司、流动 vs 合计、本期 vs 上期。要做就必须是带报表定位的语义解析
＋ 逐值 provenance（页码/报表名/原始行）＋ 交叉校验（资产 = 负债 + 所有者权益，
流动 + 非流动 = 合计），对不上就 fail-closed 不出数。

## 5. 更便宜的替代：akshare（已实测）

akshare **本来就是本项目的声明依赖**（`pyproject.toml` + `constraints.txt` 锁
1.18.80）。一次调用：

```
ak.stock_financial_abstract(symbol="600011")   →  80×104，季度粒度
  资产负债率 20251231 = 65.262893
  归母净利润 = 1.440955e+10    营业总收入 = 2.292881e+11
  经营现金流量净额 = 6.721290e+10    另有 商誉 / ROE
```

`资产负债率 65.262893` 与本文 §4.1 手算的正确值 65.3% 吻合，也与年报原文一致
——**它独立证伪了朴素 PDF 解析给出的 28.6%**。

| | 巨潮 PDF | akshare |
|---|---|---|
| 取数 | 公告查询 → 下载 → pypdf → 语义解析 | 一次函数调用 |
| 合并/母公司、流动/合计 同名行歧义 | 要自己消 | 不存在 |
| 交叉校验 | 必须自建（防解析错） | 仍建议做（防数据源错） |
| 粒度 | 年报/季报 PDF | 季度，多年 |
| 版式泛化风险 | **未知（n=1）** | 无 |
| 依赖 | 需新建管道 | 已在 `constraints.txt` |

代价：权威性降一级（第三方聚合 vs 交易所原文），且本项目对 akshare 有超时前科。
巨潮 PDF 应保留给真正需要原文佐证的场景——serenity 深度研究本就该用它。

## 6. 决策与重启条件

- **P0 取数挂起。** 排在它前面的两个约束才是真正卡住系统的：策略注册表为空
  （无任何策略过闸）、研究平面无消费端（B1/B2 未定）。这两个不解决，P0 产出的
  红旗没有东西可以否决。
- **P1 纯打分器照常合入**（`skills/common/deterministic_screen.py`，PR #180）。
  它是纯函数，与取数解耦，将来接任何数据源都能用。
- **若重启**：用 akshare 起步；只覆盖**持仓 + 有效推荐**（几十只），不碰全量
  558 个目标；交叉校验照做。

## 7. 边界与未解决项

- **n=1**：巨潮实测只覆盖一家公司、一份年报、一种排版。不同交易所/年份/编报
  软件的版式差异**未知**，不能由这一次推断通用性。
- P1 的 9 条测试全部是为压规则边界构造的**合成样本**，不代表任何真实公司，
  **不构成「这套规则在 A 股有效」的证据**。
- §4 中对华能国际打出的 3/3 无红旗**不是投资判断**，只是链路验证。
- akshare 侧只验证了 `stock_financial_abstract` 一个接口、一只标的；全市场
  覆盖率与稳定性未测。
