# A Stock Agent Engineering Contract

This repository implements decision support for China A shares. It collects
evidence, evaluates strategies, records recommendations, and monitors risk. It
must never place orders or represent analysis as a substitute for the user's
final decision.

## Non-Negotiable Rules

- Apply SSE/SZSE cash-equity T+1 rules to every execution plan.
- Never recommend selling shares bought or added on the same trading day.
- Every directional recommendation must pass announcement, data-quality,
  tradeability, price-plan, and portfolio-risk checks.
- Missing, stale, future-dated, or uncovered calendar data fails closed.
- Do not infer holdings, subscriptions, or cancelled topics from chat history.
- Do not hardcode live stocks, sectors, themes, balances, or positions in
  `AGENTS.md`, `SKILL.md`, prompts, or cron commands.
- Runtime targets come from `portfolio.json`, `monitor_registry.json`, and
  bounded candidate artifacts through `skills/common/runtime_targets.py`.
- A manual cancellation is a persistent tombstone. Automatic discovery must
  not reactivate or reintroduce the cancelled target.
- No strategy may influence live ranking before passing the research gate.
- No external-data failure may be silently interpreted as neutral evidence or
  absence of risk.
- Take, borrow, and follow momentum only. Never emit an order plan whose
  purpose is to move a price or induce other participants to follow: no
  self-reinforcing order ladders, no quote-and-cancel sequences, no
  "ignition" logic. Historical case studies of such behaviour are research
  material, never an executable strategy.
- Never act on inside information, undisclosed information, or unverified
  rumours, and never emit false or misleading statements about a security.
- Dragon-tiger (龙虎榜) seat data is a confirmation, crowding, and post-mortem
  variable only. It must never be an independent buy factor, and it must never
  enter live ranking weights.

## Runtime State

- All paths are resolved by `skills/common/paths.py`.
- Hermes and OpenClaw on one machine must share `A_STOCK_STATE_HOME`.
- Multiple machines require a shared state store plus cross-machine lease
  semantics; local files alone do not provide distributed exclusion.
- Before explaining current holdings or signals, load
  `python scripts/agent_runtime_context.py`.
- Canonical events are appended to `signal_ledger.jsonl`; derived JSON files
  are caches or projections, not competing ledgers.

## Canonical Flow

```text
provider adapters -> versioned market snapshots -> run-scoped DAG
    -> strategy evidence -> portfolio/risk policy -> signal ledger
    -> T+1/T+3 settlement -> performance gate -> policy feedback
    -> Hermes/OpenClaw explanation and delivery
```

## Scheduled Jobs

- `cron/hermes-cron-manifest.json` is the schedule source of truth.
- Enabled commands must enter through
  `python scripts/run_agent_dag.py <job-id> --emit-target`.
- Business scripts run in isolated child processes through
  `agent_job_runner.py`; they do not share the conversation context.
- Every run writes an artifact containing `trading_date`, `batch_id`, status,
  dependency results, source versions, and bounded output.
- Required dependency failure produces `status=blocked`; downstream work does
  not start.
- High-frequency jobs are silent when no threshold is triggered.
- Do not restore `cron/wrappers/` compatibility scripts.

## Analysis Boundaries

- "Full market" means enumerating the full eligible universe, not presets.
- Candidate discovery, auction, and open confirmation use fresh run-scoped
  artifacts only.
- Serenity research is generated by an agent and cached; schedulers may queue
  work but may not fabricate research scores.
- Chanlun evidence is display-only until registered as allowed for live use.
- Social attention may adjust ranking only with the configured independent
  source coverage; single-source results remain descriptive.
- Directional output must state evidence time, confidence, entry conditions,
  invalidation, risk, position sizing, holding horizon, and T+1 constraints.

## Change Protocol

- Prefer existing adapters and shared state modules over new local helpers.
- Do not add dependencies without an explicit requirement.
- Keep changes scoped and preserve unrelated local work.
- Add regression tests before changing unprotected behavior.
- Update the relevant focused documentation, not this contract, for operational
  examples or provider-specific details.
- Commit messages follow the repository Lore trailer protocol when requested by
  the active workspace instructions.

## Verification

Run the checks appropriate to the change:

```bash
pytest -q
python scripts/validate_cron_manifest.py
python -m ruff check .
git diff --check
```

If a check cannot run, report the exact missing prerequisite and the remaining
risk. Do not claim completion without reading the verification output.

### Interpreter matrix

CI runs a matrix (`3.10`, `3.13`); the local `.venv` is 3.13 only, so a green
local run is evidence for one half of the matrix and none for the other. When a
change touches `third_party/`, uses newer syntax, or adds a dependency, also run
the lowest matrix version before claiming completion:

```bash
uv venv --python 3.10 /tmp/py310
VIRTUAL_ENV=/tmp/py310 uv pip install -c constraints.txt -e ".[dev]"
/tmp/py310/bin/python -m pytest -q
```

Trigger: the vendored `third_party/chan_py_reference` uses `typing.Self` (3.11+),
so five differential tests failed at collection on 3.10 while the local 3.13 run
reported 2090 passed (PR #144, 2026-08-02).
