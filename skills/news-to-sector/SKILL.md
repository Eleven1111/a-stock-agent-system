# News to Sector v2 — 资讯驱动板块分析

给定任何财经资讯（期货涨跌、政策发布、行业新闻），自动分析该事件对 A 股各板块的传导路径、影响方向，并标记逻辑方向与盘面表现之间的预期差。遇到政策类资讯时，先调用
`policy-intent-decoder` 确认官方来源位阶、真实意图、工具硬度和执行主体，再做板块映射。

## 触发方式

用户提到以下关键词时自动触发：
- "这个新闻对哪个板块有影响"
- "根据这个资讯分析板块"
- "这个消息利好什么利空什么"
- "这条新闻怎么看"
- 任何包含"期货涨跌"、"涨停"、"利好"、"利空"的资讯分析需求

也可手动加载：`/skill news-to-sector`

## 使用

```bash
# 分析一条资讯
python3 ~/.hermes/skills/news-to-sector/scripts/main.py "焦煤期货主力合约触及涨停，涨幅8%，报1387.5元/吨"
```

## 五步分析框架

### 第一步：新闻解析
提取：商品/标的物、事件方向（涨/跌）、幅度、事件类型

若事件类型是政策、监管、会议定调或官媒表述变化，先执行 `policy-intent-decoder`：

- 只有官方来源可核验、政策硬度足够、传导链明确时，才把它作为有效催化。
- 官媒铺垫、券商解读或市场传闻只能作为观察项，不能直接写成政策利好。
- 输出板块方向时要说明政策解决的问题、配套工具和失效条件。

### 第二步：产业链映射
18条产业链知识图谱，覆盖：
- **黑色系**：焦煤、动力煤、螺纹钢、铁矿石
- **能源**：原油
- **有色**：铜、铝、镍、黄金、碳酸锂
- **化工**：纯碱、PTA、橡胶
- **农产品**：豆粕、玉米、白糖、生猪
- **航运**：BDI/海运

### 第三步：实时验证
用东方财富 API 查询受影响板块的当日涨跌幅，验证产业链逻辑是否已在盘面兑现

### 第四步：预期差分析 ⭐
自动识别逻辑方向与实际盘面的偏差：
- 利好板块实际在跌 → "利好尚未兑现"
- 利空板块实际在涨 → "利空被消化或有其他利好对冲"

### 第五步：市场全景
显示当日涨幅 TOP 5 / 跌幅 TOP 5 板块，提供交叉参考

## 局限性

- 产业链映射基于静态知识图谱，不覆盖所有商品
- 预期差分析仅提示方向偏差，不解释偏差的具体原因
- 东方财富 API 在非交易时间可能不可用，见 `references/data_sources.md` 的备用API
- ⚠️ **ClashX TUN 模式**会阻断 `push2.eastmoney.com`（DNS 假 IP `198.18.x.x`），导致板块实时行情无法获取。TUN 模式下建议用 `a-stock-data` 技能的腾讯 API 降级方案
- 实际市场受多重因素影响，产业链传导只是其中一个维度
