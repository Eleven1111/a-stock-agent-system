# REC-001 事故复盘：国联股份错误推荐

> 日期：2026-06-03
> 严重程度：🔴 信任损失（>财务损失）

## 经过

用户问"互联网和电商有哪些不错的标的"，agent推荐了国联股份(603613)。
用户信任推荐并买入500股 @ 23.13，总仓位57.8%。
用户后续要求复盘时，agent发现自己无法回溯推荐记录（对话上下文已压缩）。
用户质问"以后怎么能知道你的推荐哪些可信" — 暴露出**无审计档案的系统性缺陷**。

## 根因

1. **先有结论再找数据**：用户问互联网电商，国联属于此板块→直接推荐，跳过了全量扫描
2. **赛道偏好覆盖客观规则**：B2B电商+PE12.7便宜+RSI超卖，觉得"好"就推荐了，无视空头排列锁分-0.5
3. **低PE陷阱**：PE12.7看似便宜，但净利润同比-9.12%，这种"便宜"是价值陷阱
4. **无审计档案**：推荐无法追溯，用户无法验证agent的判断能力

## 修复措施

### 即时修复（SKILL.md + AGENTS.md）

1. **全量扫描六步规程**：先全量再聚焦，顺序不可倒置
2. **禁入条件**：5条硬性条件，违反任意一条禁止给买入建议
3. **推荐审计档案**：`data/recommendations.json`，每笔推荐同步写入
4. **用户可随时审计**：说"审计"/"推荐记录"即读取审计文件

### 禁入条件对照（国联违反情况）

| 条件 | 国联当时状态 | 违反？ |
|------|------------|:------:|
| 空头排列 | MA5<MA10<MA20<MA60 | ✅ |
| 净利润同比下降>10% | 净利润-9.12% | ✅（接近） |
| PE为负 | PE=12.74 | ❌ |
| 布林跌破下轨 | 未跌破 | ❌ |
| RSI超卖+空头排列 | RSI 29.2 + 空头 | ✅ |

### 系统层修复

- 记忆已更新：赛道偏好不降低评分门槛
- AGENTS.md已更新：推荐审计铁律+全量扫描执行规程
- SKILL.md已更新：禁入规则+审计档案

## 教训总结

"超卖+低PE" ≠ 买入信号。趋势向下时，超卖是下跌中继不是洗盘底。

**信任一旦丢了，RE比分红率更难修复。**
