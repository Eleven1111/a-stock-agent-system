# 反身性分析框架（v2 — 含特殊买家维度）

> 基于索罗斯反身性理论 + A股资金结构特征的打板判断框架。
> 核心命题：打板本质是在反身性循环的繁荣期上车，但循环会被不同类型的资金扭曲。

## 反身性基础模型

```
传统反身性循环：
  股价涨 → 更多人看到 → 资金买入 → 股价继续涨
   ↑_____________________________________↓
   （同质化资金，线性反馈）

修正后反身性循环（考虑资金结构）：
  股价涨 
   ├─ 游资看到 → 拉板吸筹 → 席位溢价 → 散户跟风 → 涨加速
   ├─ 量化看到 → 算法秒封 → 假封单 → 撤单 → 涨速扭曲
   ├─ 散户看到 → 追涨 → 轻度助涨
   └─ 机构/大股东看到 → 逢高减持 → 涨势打断
```

## 四种关键买方的反身性行为特征

### ① 游资（传统打板资金）— 反身性的启动器

| 特征 | 判断方法 |
|:----|:--------|
| 封板时间 | 非秒封，经历吸筹~拉板~封板的完整过程（30分~数小时） |
| 封单稳定性 | 封住后≥10分钟不撤单 |
| 席位效应 | 知名席位买入→吸引跟风盘→强化反身性 |
| 对反身性的贡献 | 最强。有"席位背书效应"，买=给散户信心 |

**游资主导的信号：** 低开高走涨停、午后封板、早盘洗盘后拉板

### ② 量化机构 — 反身性的加速器和扭曲器

| 特征 | 判断方法 |
|:----|:--------|
| 封板速度 | **秒级封板**（竞价结束到封板<3秒）|
| 封单行为 | 封单量大但极不稳定，频繁撤单 |
| 竞价特征 | 第二天竞价量异常大（几十万手竞价单） |
| 对反身性的贡献 | 扭曲。加速涨速但制造假信号，涨停可能是"算法共识"而非"市场共识" |

**量化主导的信号：** 早盘秒板、封单忽大忽小、炸板后秒回封

**量化对打板的影响：**
- 繁荣期缩短（以前热3天，量化介入后热1天）
- 炸板率增高（量化撤单制造假封单，当前盘面50%炸板率中有大量量化贡献）
- 第二天低开率增高（量化竞价砸盘）

### ③ 机构/大股东 — 反身性的打断器

| 特征 | 判断方法 |
|:----|:--------|
| 卖出方式 | 大宗交易、集合竞价砸盘、被动减持公告 |
| 触发条件 | 股价涨到一定程度→解套/达到减持价 |
| 对反身性的贡献 | **打断循环。** 不管多少买盘在涌入，大股东减持公告可以一刀切断反馈 |

**机构卖出信号：** 近期有减持公告、大宗交易折价率大、龙虎榜出现机构专用席位卖出

### ④ 潜伏盘 — 反身性的反向力量

| 特征 | 判断方法 |
|:----|:--------|
| 来源 | 长期横盘期的老股东、定增解禁、员工持股解禁 |
| 卖点 | 涨停→解套→卖 |
| 对反身性的贡献 | 涨停初期制造抛压，封单质量下降 |

## 反身性检查四步法

任何打板推荐前，必须完成以下检查（写入审计文件）：

### 第一步：反馈方向判断

| 状态 | 条件 | 操作 |
|:----|:----|:----|
| ✅ 向上加速 | 涨停数递增、连板高度在增加 | 繁荣期，参与 |
| ⚠️ 趋平 | 涨停数不变、高度不突破 | 平台期，谨慎 |
| ❌ 向下反转 | 涨停数减少、高度压缩 | 衰退期，放弃 |

### 第二步：资金结构判断

| 类型 | 特征 | 反身性可靠性 |
|:----|:----|:------------|
| 游资主导 | 慢拉板（30分~数小时），封单稳定 | ✅ 可靠 |
| 量化主导 | 秒封板（<3秒），封单忽大忽小 | ⚠️ 不可靠，放弃 |
| 混合型 | 炸板后秒回封 | ⚠️ 谨慎，控仓位 |
| 有减持公告 | 任何资金结构 | ❌ 打断风险 |

### 第三步：催化强度判断

- 有实质催化（政策/财报/行业数据）→ 反身性有支撑
- 纯情绪驱动（无实质消息）→ 反身性脆弱

### 第四步：综合评级

| 资金结构 | 反馈方向 | 催化 | 可操作性 |
|:--------|:--------|:----|:--------|
| 游资主导 | 向上加速 | 有实质催化 | ✅ 最可靠 |
| 游资+量化混合 | 向上加速 | 有催化 | ⚠️ 参与但控仓位 |
| 量化主导 | 秒板 | 无实质催化 | ❌ 放弃 |
| 任何结构 | 衰退期 | 任何 | ❌ 放弃 |
| 前高附近+减持 | 向上 | 任何 | ⚠️ 只做1进2，不恋战 |

## 量化参与度速查表

| 观察指标 | 量化主导 | 游资主导 | 混合 |
|:--------|:-------:|:-------:|:----:|
| 封板速度 | <3秒 | >30分钟 | 3秒~30分 |
| 封单稳定性 | 频繁撤单 | 稳定≥10分钟 | 偶尔撤单 |
| 炸板率 | >50% | <30% | 30~50% |
| 竞价次日量 | 异常大 | 正常 | 中等 |
| 建议态度 | ❌放弃 | ✅参与 | ⚠️谨慎 |

## 反身性与禁入条件的联动

| 禁入条件 | 反身性解释 |
|:---------|:----------|
| 空头排列不推荐 | 空头=反身性向下循环未结束，低PE+下跌=价值陷阱 |
| 净利润降>10%不推荐 | 盈利下降→估值变便宜→继续跌→PE更便宜，这是反身性陷阱的经典形态 |
| 亏损股不推荐 | PE为负=反身性失效，没有"便宜"一说 |
| 跌破布林下轨不推荐 | 加速下跌中，反身性向下加速尚未衰竭 |
| RSI超卖+空头不推荐 | 下跌中继，不是洗盘底。反身性向下循环中的短暂停顿 |

## 实战应用：京能电力(600578)反身性分析示例

2026-06-03情况：

**反馈方向：** 电力板块热度23.0分全市场第一，今日7家涨停，向上加速 ✅

**资金结构：** 低开高走非秒封（8.24→9.34耗时近5小时），游资主导特征 ✅
- 5月那波5连板后跌停（量化+游资共振后砸盘可能）
- 前高10.05有套牢盘 ⚠️

**催化强度：** 夏季用电高峰预期 + 公司"提质增效"行动方案 ✅

**综合评级：** 游资主导+向上加速+有催化 → ✅ 最可靠
- 但前高附近套牢盘 → 只做1进2，不恋战
