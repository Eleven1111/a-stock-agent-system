# 8个拓展场景定义

> 全部场景基于现有 skill 组合，通道已通，按需逐场景开通 cron。

## 场景1：连板追击 🎯
**触发条件**：hot-money-tactics 检测到 ≥3连板 + 封板资金>1亿
**分析链**：hotmoney→板块热度→封板质量→次日竞价预判
**输出**：追板建议（竞价区间、封板概率、炸板风险）
**状态**：⏳ skill定义完成，待开通 cron

## 场景2：抄底策略 📉
**触发条件**：stock-analyst 检测到 RSI<25 + 价格跌破布林下轨 + 缩量
**分析链**：技术面→基本面验证→催化剂搜索→PE分位数判断
**输出**：抄底区间、仓位建议、反弹目标、止损位
**状态**：⏳ skill定义完成，待开通 cron

## 场景3：板块轮动 🔄
**触发条件**：连续3日板块资金流向反转 + hot-money --rotation 检测退潮
**分析链**：退潮板块识别→新热点萌芽→轮动方向研判
**输出**：撤离板块 + 埋伏板块 + 轮动时间窗口
**状态**：✅ 部分实现（hot-money-tactics --rotation），待自动化

## 场景4：政策驱动 📜
**触发条件**：资讯监控 cron 检测到国务院/发改委/工信部重大政策
**分析链**：news-to-sector 产业链映射 → 受益标的技术面扫描 → 催化持续性评估
**输出**：受益板块排序 + 龙头标的 + 政策持续性（脉冲/结构/趋势）
**状态**：✅ 资讯监控 cron 已开通(job:5536d)，触发词覆盖政策类

## 场景5：事件驱动 ⚡
**触发条件**：关键公司财报/新产品发布/行业展会
**分析链**：标的基本面速览→同板块联动分析→事件确定性评估
**输出**：事件影响标的池 + 时间窗口 + 确定性评级
**状态**：⏳ 需单独配置事件日历 + cron

## 场景6：北向跟踪 🧭
**触发条件**：北向资金连续3日净流入/流出 TOP5
**分析链**：北向偏好板块→标的筛选→技术面共振验证
**输出**：北向偏好板块 + 跟随标的 + 跟风性价比判断
**状态**：⏳ 需北向资金数据端点（东财API需NO_PROXY）

## 场景7：技术突破 🚀
**触发条件**：stock-analyst screener 检测到突破关键阻力位 + 放量
**分析链**：突破有效性验证→量价配合→回踩支撑→目标测量
**输出**：突破标的 + 买入区间 + 止损位 + 目标位
**状态**：✅ stock-analyst screener 已支持，待自动化信号触发

## 场景8：估值修复 💎
**触发条件**：PE<历史20%分位 + 业绩增长>15% + 股价横盘>30日
**分析链**：估值压缩原因分析→催化剂搜索→行业横向对比
**输出**：修复概率 + 修复空间 + 时间预估 + 仓位建议
**状态**：⏳ 需基本面数据完善（BaoStock + 历史PE分位）
