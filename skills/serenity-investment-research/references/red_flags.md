# 红旗清单（Red Flags）

命中任何一条：

1. 用 `evidence_ledger.py add --claim-type red_flag` 入账（每条红旗一条记录，
   注明证据来源与日期）。
2. 压低 scorecard 的 `financial_quality` 和/或 `risk_control` 评分；按 Mainline
   Policy Role，任一维度 `<= 2/5` 即硬否决，阻断正向动作。
3. 报告必须有专门章节（「红旗清单」）列出全部 red_flag 条目，不允许只挑部分披露。

## 财务类

| 红旗 | 说明 |
|---|---|
| 存货/应收增速 > 营收增速 | 塞货、议价力弱或需求虚假繁荣 |
| 声称环节稀缺但毛利率不升 | 真卡点应有定价权；毛利率平或降说明稀缺是讲的 |
| 经营现金流长期低于净利润 | 利润质量差，利润可能是应计出来的 |
| 机会兑现前需要再融资 | 定增/转债在故事兑现前落地 = 现有股东先被稀释 |
| 关联交易占比高且定价模糊 | 利润可被体外调节 |

## 业务与信披类

| 红旗 | 说明 |
|---|---|
| 管理层蹭主题但分部数据不变 | 互动易/公告积极表态，分部收入、在建工程、研发投入都没动 |
| 依赖单一未具名客户的传闻 | 「某北美大客户」类传闻无 S/A 证据支撑 |
| 同一问题被交易所反复问询且回复含糊 | 信披质量差，管理层回避 |
| 扩产声明无环评/备案/资本开支佐证 | 意向性扩产，不是产能 |
| 宣称进口替代但海关进口量未降 | 替代故事与数据背离 |

## 交易与市场类

| 红旗 | 说明 |
|---|---|
| 社媒驱动的股价异动 | 涨幅由帖子/短视频驱动而非订单、财报或政策 |
| 大股东高比例质押 + 股价接近平仓线 | 被动卖压风险 |
| 限售解禁窗口临近 + 利好密集释放 | 配合减持的信披节奏 |

## 边界

- 红旗是「必须解释、必须压分」的证据，不是自动否决整个标的：报告可以在披露和
  压分之后仍给出结论，但不得隐藏或淡化。
- 反过来，没有红旗不等于安全；红旗清单只覆盖常见造假与错配模式。
