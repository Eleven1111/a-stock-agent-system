# Sector Playbook: Embodied AI and Humanoid Robotics

Use this playbook for embodied AI, humanoid robots, mobile manipulation, robot actuators, dexterous hands, and related supply chains.

## Commercialization Clock

Classify the sector stage:

| Stage | Evidence |
|---|---|
| Lab demo | Videos, prototypes, no customer deployment |
| Pilot | Customer trials, small fleet deployment, limited use cases |
| Early production | Repeat deployments, public production line, named customers, service contracts |
| Scaling | Thousands of units, unit economics improving, supplier capex confirmed |
| Mature | Multiple profitable vendors and stable replacement cycle |

## Supply-Chain Map

```text
AI model / data / simulation
-> robot control stack and edge compute
-> actuator and sensing system
-> joint module / dexterous hand / mobile base
-> full robot OEM
-> deployment integrator
-> factory, logistics, inspection, service, home
```

## High-Priority Chokepoint Nodes

| Node | Why it matters | Evidence to demand |
|---|---|---|
| Joint actuator module | High value per robot, reliability-critical, integrates motor/reducer/sensor/drive | Named customer, production capacity, unit economics, failure-rate data |
| Dexterous hand | Determines useful manipulation, high precision and miniaturization requirements | Customer validation, repeatable task benchmark, tactile integration |
| Force/tactile sensors | Needed for contact-rich work and safety | Calibration accuracy, durability, production yield |
| Ball/planetary roller screw | Key for linear actuation and compact power density | Process capability, lifetime testing, customer qualification |
| Harmonic / planetary reducer | Precision, backlash, durability | Volume shipment to robot customers |
| Frameless torque motor / hollow cup motor | Power density and motion quality | Robot-specific revenue or design wins |
| Encoder / IMU | Feedback quality and safety | Reliability, precision, temperature stability |
| Edge compute | Real-time inference and control | Platform adoption, developer ecosystem |
| Thermal / power / battery | Runtime and safety | Pack-level data, customer deployments |

## Watchlist Buckets

Use buckets, not blind stock lists:

| Bucket | What to verify |
|---|---|
| True bottleneck suppliers | Revenue/orders from robot customers, hard-to-replace capability |
| Adjacent industrial leaders | Transferability from automotive/industrial automation to robots |
| Theme proxies | Market-traded exposure with weak direct revenue |
| OEMs | Deployment, gross margin, uptime, repeat customers |
| Software/platform | Ecosystem lock-in, compute attach, developer adoption |

## Common False Positives

- "Layout" or "reserve technology" without customer validation.
- One-time sample orders presented as mass production.
- Industrial robot revenue mislabeled as humanoid exposure.
- Customer confidentiality used to hide absence of volume.
- Gross margin ignored while chasing shipment numbers.
- A single viral robot video treated as commercialization.

## Required Bear Case

Every humanoid robotics report must answer:

1. What if humanoid form factor is slower than expected and mobile manipulators win first?
2. What if OEMs vertically integrate the high-value actuator stack?
3. What if price declines faster than supplier cost reductions?
4. What if safety and liability delay deployment outside factories?
5. What if the best alpha is already priced into A/H robotics theme stocks?

## Tracking Metrics

| Metric | Why it matters |
|---|---|
| Unit shipments by OEM | Confirms commercialization stage |
| Repeat customer deployments | Separates pilots from real ROI |
| Actuator / hand / sensor revenue | Validates supplier exposure |
| BOM cost decline | Determines adoption curve |
| Gross margin by segment | Shows value capture |
| Capex for robot-specific production | Confirms management commitment |
| Failure rate / uptime | Determines industrial usability |
| Named customer or application | Reduces rumor risk |
