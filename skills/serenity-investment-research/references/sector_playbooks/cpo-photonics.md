# Sector Playbook: CPO and Photonics

Use this playbook for co-packaged optics, silicon photonics, optical engines, lasers, modulators, photodiodes, PICs, substrates, packaging, and datacenter optical interconnects.

## Bottleneck Map

```text
AI cluster bandwidth demand
-> switch ASIC / optical I/O
-> CPO / pluggable optics / LPO alternatives
-> optical engine
-> laser / modulator / photodiode / driver / TIA
-> wafer, packaging, testing, reliability
```

## Evidence to Demand

| Claim | Evidence |
|---|---|
| Demand | Hyperscaler capex, switch roadmap, bandwidth requirements |
| Qualification | Named customer or standards ecosystem, reliability testing |
| Bottleneck | Limited supplier count, long qualification, proprietary process |
| Value capture | Revenue ramp, margin expansion, ASP stability |
| Catalyst | Customer production, conference demo, standards, earnings guidance |

## Common False Positives

- Lab demo without reliability or temperature data.
- Optical component supplier with no AI datacenter customer.
- Treating all datacom optics as CPO exposure.
- Ignoring incumbent pluggable optics and LPO competition.
