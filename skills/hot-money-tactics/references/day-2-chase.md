# 1进2 打板操作手册

首板次日追涨停的标准流程。

## 核心原则

**1板后第二天不是必然能追的。** 判断依据：竞价表现 + 开盘后15分钟确认。

## 时间线

```
前一晚  → 记住今天涨停股的价格、封单、板块逻辑
9:15~9:20  竞价第一阶段（可撤单，假的多，不参考）
9:20~9:25  竞价第二阶段（不能撤单，相对真实）
9:25       产生开盘价 ← 第一判断节点
9:30       正式开盘（第一笔成交噪声大，不参考）
9:35~9:40  开盘消化完毕 ← 最佳判断时点
```

## 判断逻辑

### 竞价阶段（9:25）

| 竞价结果 | 含义 | 动作 |
|---------|------|------|
| 开盘价在昨日涨停价基础上涨 5%+ | 资金抢筹，1进2概率大 | 先别买，看开盘 |
| 开盘价涨 0~4% | 分歧大，非一致性看多 | 等9:35判断 |
| 开盘价平开或低开 | 无接力动力 | **放弃** |

### 开盘确认（9:35）

| 情况 | 判断 | 操作 |
|------|------|------|
| 秒封涨停 | 1进2成功 | 买不进，放弃 |
| 站昨日收盘价以上，量能放大 | 有资金承接 | 可在昨收+0~3%区间买入 |
| 冲高回落跌破昨收 | 诱多出货 | **放弃** |
| 直接低开低走 | 昨天的涨停是跟风 | **放弃** |

## 买入区间设定

```python
buy_zone_low = 昨日收盘价
buy_zone_high = 昨日收盘价 * 1.03  # 最多+3%
stop_loss = 昨日收盘价 * 0.92     # -8%
```

## 仓位

- 打板是短线博弈，**单次仓位不超过可用资金的30%**
- 试仓优先：1手起步，不一把重仓

## 退出

- 当天不能封板 → 第二天开盘走
- 封板成功 → 第二天看竞价，+5%以上继续拿着，平开直接出

## 运行时订阅覆盖

竞价阶段先读取当前有效订阅并检查异常，再处理前一日涨停池和全市场发现池。
订阅对象仍必须通过同一套模式、可成交性、公告、仓位和 T+1 门禁，不得因为被关注而放宽规则。
