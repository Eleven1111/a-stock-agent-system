## 为什么打板能赚钱（核心原理）

打板的根本原理不是技术分析，而是**反身性自反馈循环**（索罗斯, 1987）：

```
一只股票涨停 → 出现在涨停列表 → 游资/散户看到 → 更多人关注
    ↓                                                     |
这只票变成"板块龙头" → 媒体报道 → FOMO情绪               |
    ↓                                                     |
更多资金追进来 → 继续涨停                                  |
    ↓                                                     |
股价上涨 → 公司"看起来更值钱" → 基本面被重新定价           |
    ↓                                                     |
......直到没有人接盘 → 踩踏下跌                           |
    └─────────────────────────────────────────────────────┘
     自反馈循环：价格改变认知，认知改变价格
```

**打板选手的盈利来源：** 在正反馈循环的早期（首板/2板）上车，在负反馈开始（炸板潮/放量不涨）前下车。赚的不是公司价值，是**反馈惯性**的钱。

## 三层打板筛选模型

```
第一层：全量扫描 → 找出"资金在打的板块"
  工具：sector_scan.py（涨停聚合）+ hot-money-tactics --rotation（轮动）
  指标：涨停数 × 出现天数 × 连板高度 = 热度分
  理论：动量策略（Jegadeesh & Titman 1993）——过去强者未来继续强
  输出：热度分矩阵 + 持续/新冒头/退潮板块标注

第二层：板块内选股 → 筛出具体标的
  过滤器：
    ├─ ✅ 多头排列（MA5>MA10>MA20>MA60）
    ├─ ✅ 封单质量（封单/流通市值比）
    ├─ ✅ PE合理（非亏损，非泡沫估值）
    └─ ✅ 1手价格 ≤ 用户可用资金
  排除器（禁入条件，来自 stock-triage AGENTS.md）：
    ├─ 🚫 空头排列
    ├─ 🚫 净利润同比下降 > 10%
    ├─ 🚫 PE为负（亏损股）
    ├─ 🚫 布林跌破下轨（"加速下跌中，等待企稳"）
    └─ 🚫 RSI超卖 + 空头排列（"下跌中继非洗盘"）

第三层：竞价确认 → 决定是否进场
  关键时点：9:25竞价出价 → 9:35开盘确认（非9:30，等5分钟消化脉冲）
  判断逻辑：
    ├─ 小高开 0~3% → ✅ 最佳击球区，上车
    ├─ 高开 3~5% → ⚠️ 偏强，等回踩再考虑
    ├─ 高开 >5% → ❌ 太猛了，放弃
    └─ 平开/低开 → ❌ 转弱，放弃
```

## 反身性全维度检查（特殊买家）

传统反身性模型假设资金同质化——这忽略了 A 股市场上**不同类型的买家**对反身性的影响完全不同：

```
              影响方式          反身性贡献      可预测性
───────────────────────────────────────────────────────
游资（传统）   慢慢吸→硬拉→派发   中（有席位背书）  高
量化（机器）   秒抢→秒撤→竞价砸   高（加速反馈）    低
散户（跟风）   看到涨停才追       高（FOMO燃料）    中
机构（大资金）  基本面驱动         低（打断反馈）    高
大股东/潜伏盘  解套就卖           负向（打断反馈）   中
```

### ① 量化——反身性的加速器与扭曲器

```
传统反身性：   涨→人看到→人买→涨（小时级）
量化反身性：   涨→算法检测到→AI抢买→涨更快→AI止盈→闪崩（秒级）

量化在打板中的典型操作：
  涨停前300ms：算法检测到买盘加速 → 抢板
  封板瞬间：大单堵门 → 2秒内撤单留板（制造假封单）
  第二天竞价：高开 → 第一时间砸盘出货
```

量化对打板的影响：
- **加速繁荣期** — 以前游资拉板要半小时，量化3秒封死
- **制造假信号** — 量化抢的涨停没有"市场共识"，第二天常低开
- **炸板率上升** — 量化撤单极快，封单看起来大但下一秒可能全撤
- **判断量化参与度：** 秒封（<30秒）→ 量化概率高 | 撤单率 > 30% → 量化制造假封单 | 第二天竞价量异常大 → 量化砸盘概率高

### ② 游资——反身性的启动器

游资与量化本质区别：游资有**席位背书效应**。知名游资席位买入 → 散户跟风 → 反身性形成。量化没有这个效应（没人跟算法代码买）。

**游资参与度判断：** 封板时间 > 30分钟（非秒封）→ 游资主导 | 封单稳定 > 10分钟不撤 → 真游资 | 低开高走涨停板 → 典型游资洗盘手法

### ③ 大机构/大股东——反身性的打断器

无论多少游资和散户在买，一个大股东减持公告或机构大宗卖出，直接切断反馈循环。

**机构风险检查：** 近期是否有减持公告？本月是否有大宗交易？大股东质押比例是否过高？

### ④ 潜伏盘——反身性的反向力量

涨停→老股东解套→卖出→封单被吃→反身性循环还没开始就结束。

## 反身性综合判断流程

```python
def assess_reflexivity(stock_data):
    score = 0

    # 1. 反馈方向
    if 板块热度加速上升: score += 2
    elif 板块热度趋平: score += 1
    elif 板块热度下降: score -= 2

    # 2. 特殊买家判断
    if 封板时间 < 30秒: score -= 1  # 量化参与高，反馈不可靠
    if 游资席位可见且稳定: score += 2
    if 近期有大股东减持: score -= 3  # 直接打断反馈
    if 炸板率 > 40%: score -= 1     # 反馈衰竭信号

    # 3. 催化支撑
    if 有强政策/行业催化: score += 2
    if 无催化仅资金驱动: score -= 1

    # 结论
    if score >= 3: "强反身性，可参与"
    elif score >= 1: "中等，控制仓位"
    else: "弱反身性，不追板"
```

## 反身性强弱速判

### 强反身性（可追板）
- 板块热度连续3天+加速
- 游资主导，封板稳定（非秒封）
- 有实质催化支撑
- 龙虎榜有知名席位

### 弱反身性（不追）
- 秒封→大量量化参与
- 无催化，纯资金驱动
- 近期有大股东减持或大宗交易
- 炸板率 > 40%

## 反身性衰竭信号

1. 跟风股先于龙头跌
2. 板块内涨停数下降但龙头还在涨（孤立无援）
3. 炸板率连续2天上升
4. 第二天竞价量异常放大（量化砸盘）
5. 从加速板变为烂板（分歧加大）

## 涨停分时形态分类

| 形态 | 特征 | 判断 |
|:----|:-----|:-----|
| **低开高走板** | 开-2~-5%→拉涨停 | 游资洗盘，强势 ✅ |
| **秒封板** | 开盘30秒内封死 | 量化+游资合力，但量化撤单风险 ⚠️ |
| **烂板** | 涨停后反复开合 | 分歧大，封板率低 ❌ |
| **尾盘板** | 14:30后拉涨停 | 手法猥琐，第二天低开概率高 ❌ |
| **一字板** | 开盘就封死 | 买不到，买到就是坑 ❌ |
| **趋势板** | 沿MA5/MA10稳步上行中涨停 | 主力控盘，有一定持续性 ✅ |
