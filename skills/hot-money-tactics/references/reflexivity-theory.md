# 反身性打板理论

> 索罗斯反身性理论在A股打板场景下的应用框架。
> 2026-06-03 与用户深度讨论后整理。

## 核心原理

打板的根本原理不是技术分析，而是**反身性自反馈循环**：

```
涨停 → 列表曝光 → 关注度上升 → FOMO → 更多资金涌入 → 继续涨停
  ↑                                                     |
  └─────────────────────────────────────────────────────┘
```

打板选手盈利来源：在正反馈早期上车，负反馈开始前下车。

## 扩展：特殊买家对反身性的影响

| 买家类型 | 影响方式 | 反身性贡献 | 可预测性 |
|----------|---------|-----------|---------|
| 游资 | 吸筹→硬拉→派发，有席位背书 | 中 | 高 |
| 量化 | 秒抢→秒撤→竞价砸，算法驱动 | 高（加速） | 低 |
| 散户 | 看到涨停才追，FOMO燃料 | 高 | 中 |
| 机构 | 基本面驱动，大宗交易 | 低（打断反馈） | 高 |
| 大股东/潜伏盘 | 解套就卖 | 负向（打断） | 中 |

## 反身性强弱判断

### 强反身性（可追板）
- 板块热度连续3天+加速
- 游资主导，封板稳定（非秒封）
- 有实质催化支撑
- 龙虎榜有知名席位

### 弱反身性（不追）
- 秒封→大量量化参与
- 无催化，纯资金驱动
- 近期有大股东减持或大宗交易
- 炸板率 > 40%

## 反身性衰竭信号

1. 跟风股先于龙头跌
2. 板块内涨停数下降但龙头还在涨（孤立无援）
3. 炸板率连续2天上升
4. 第二天竞价量异常放大（量化砸盘）
5. 从加速板变为烂板（分歧加大）
