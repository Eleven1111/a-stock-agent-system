# 数据源说明 & 已知限制

## Tencent API (qt.gtimg.cn) 使用指南

本技能大部分行情数据来源于腾讯财经 API（`qt.gtimg.cn`），因为它不受 ClashX TUN 模式影响。

### GBK 编码处理

腾讯 API 返回 GBK 编码，不可直接按 UTF-8 解码：
```python
import subprocess
r = subprocess.run(['curl', '-s', 'http://qt.gtimg.cn/q=sz002156', '--noproxy', '*'],
                   capture_output=True, timeout=10)
text = r.stdout.decode('gbk', errors='ignore')
```

## 代理限制

- 本机 ClashX 当前处于 **TUN 模式**
- `push2.eastmoney.com` 和 `push2his.eastmoney.com` 被拦截
- `stock_zt_pool_em()` 仍可用（不走 push2）
- 个股详细行情 → 走腾讯 API
- 历史K线 → 无可靠替代
- 板块资金流向 → 无可靠替代（`--rotation` 用涨停家数替代）

## 已知局限

1. **龙虎榜席位数据**：AkShare 部分接口受限，暂未实现游资席位追踪
2. **盘中数据**：腾讯 API 盘中有 3-5 分钟延迟
3. **涨停板池覆盖**：`stock_zt_pool_em()` 覆盖主板/创业板/科创板 10%+，北交所 30% 需单独处理
4. **非交易日**：涨停板池返回空
