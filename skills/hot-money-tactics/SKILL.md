# 游资战法 — 涨停板全景分析

### ⚠️ 涨停板数据的盲区（必读）

本技能所有分析模块**只统计封死涨停板的股票**。部分板块可能涨幅强劲（板块平均 +2~5%、龙头 +7~8%）但**零涨停**，这类板块在本技能的报告里完全不可见（典型：煤炭板块 2026-06-08 整体走强但 0 涨停，扫不到）。

**何时必须叠加非涨停板扫描：**
- 用户问"今天什么板块热"、"有没有其他板块"、"还有什么可以看的" → 涨停板扫描 **+** 非涨停板板块趋势扫描
- 用户问具体板块名称（如"煤炭怎么样"）→ 按板块名称直接扫成分股
- 单日涨停数 < 60 只 → 市场情绪偏弱，热点可能在非涨停板趋势方向上

非涨停板扫描的候选圈定、批量代码与阈值见 `references/non-zt-sector-scanning.md`。

## 何时不用本技能

本技能是**情绪与热点的解释层**，产出市场状态判断，不产出可下单候选。

| 场景 | 改用 | 原因 |
|------|------|------|
| 要可审计、可成交的打板候选（可成交性、六问否决、T+1 处置方案、Signal Ledger 落账） | `daban-stock-picker` | 本技能脚本不做可成交性检查与 Ledger 落账；上面的「打板标的选择」只是资金适配层面的启发式筛选 |
| 要决定仓位、集中度、是否减仓 | `stock-triage` | 组合风险 Policy 的唯一归口，本技能不读组合约束 |
| 要个股 K 线、财务、技术指标 | `stock-analyst` / `a-stock-data` | 本技能只做全市场涨停面的聚合 |
| 要经过门禁的研究结论（多专家复核、证据包） | `research-committee` | 本技能的情绪判级是启发式规则，不经过策略准入 |

另有两种误用：

- **不要把情绪周期判级当成个股入场信号。** 沸点/回暖/震荡/冰点 约束的是仓位与预期，不构成任何单只标的的买入条件。
- **不要在非交易日或盘中早段取结论。** 非交易日无涨停板数据；盘中腾讯 API 有 3-5 分钟延迟，收盘后最准（见「已知限制」）。

## 关键约束与决策表（始终生效）

### 打板标的选择（资金适配）

> 优先级：候选流水线可用时，可交易结论以 `daban-stock-picker` 为准（它才做可成交性、六问否决与 Ledger 落账）。以下流程是**无流水线时的独立路径**，产出的是资金适配层面的启发式清单，不等价于已过门禁的候选。

当用户问"能打板的标的有哪些"或类似问题时，必须：

1. **查可用资金（从 portfolio.json 读真实数据）** — 运行 `portfolio_manager.py --check` 获取持仓 + 可用现金。`portfolio.json` 为空且用户本 session 口述过持仓 → **立即写入**（见 stock-triage「持仓数据持久化铁律」）；为空且未口述 → 问用户。
2. **筛掉买不起的** — 1手成本 = 现价 × 100，排除 1手成本 > 可用资金的标的；标签 ✅买得起 / ⚠️稍贵 / ❌超预算。
3. **封单质量分级**（见下表）。
4. **推荐必含字段**：`标的 | 现价 | 1手成本 | 封单(亿) | 连板 | 板块逻辑 | 操作建议 | 建议仓位`；每个标的还须附 公告质检状态、买入区间、最高追价、止损、目标、持有周期，以及 `A股T+1：当日买入不可卖出，最早可卖交易日`。公告扫描缺失或出现澄清/异常波动/监管硬风险时，只能关注或回避。

完整 7 步工作流（个股级数据提取/均线形态/历史K线/实时补全）见 `references/deep-sector-analysis.md`。

### 封单资金质量分级
| 封单/流通市值比 | 评级 |
|---|---|
| > 3% | 强封 ✅ |
| 1%~3% | 中等 |
| < 1% | 弱封，容易炸板 |

### 操作建议分类
| 情况 | 建议 |
|------|------|
| 已封死，封单强 | 排板等炸板回封，或明早竞价看 1进2 |
| 已封死，封单弱 | 不追，炸板率高 |
| 盘中未封 | 观察板块热度，急拉不打板 |
| 竞价阶段 | 看竞价量能和价格 |

> 含反身性评分的 v2 版操作表见 `references/reflexivity-theory.md`。

### 情绪周期交叉验证（8️⃣）
竞价封板率与炸板率需结合分析：
- 竞价封板率 > 80% + 炸板率 > 35% → 隔夜情绪极强但日内分歧大，警惕炸板潮
- 竞价封板率 < 30% + 炸板率 < 20% → 隔夜弱但封得稳，可能是趋势板
- 最高板 < 4板 + 涨停数 > 50 → 宽度好但高度不够，轮动快

### 1进2 关键时点（9️⃣）
- 9:25 竞价出价 → 看高开/平开/低开
- 9:35 开盘确认（**不是 9:30**，等 5 分钟消化开盘脉冲）
- 买入区间：昨收价 ~ 昨收 × 1.03

详细判断流程（竞价/开盘确认表、买入区间设定、退出）见 `references/day-2-chase.md`。

### 运行时订阅覆盖规则
- 当前有效订阅出现异常封单或竞价信号时，必须纳入同一批次分析。
- 订阅只保证被扫描，**不提高评分**，也不绕过成交、公告、资金和 T+1 门禁。
- 订阅集合从 `runtime_targets.py` 读取，手动取消墓碑必须生效。

## 已知限制

- 数据全量依赖 AkShare（东方财富数据源）；非交易日无涨停板数据。
- 龙虎榜席位数据需单独扩展（AkShare 部分接口受限，暂未实现游资席位追踪）。
- 盘中数据只在交易时段有效，收盘后最为准确（腾讯 API 盘中有 3-5 分钟延迟）。
- ⚠️ **ClashX TUN 模式**会阻断开往 `push2.eastmoney.com` 的流量（DNS 被解析为假 IP `198.18.x.x`）。已验证可绕过/降级：
  - ✅ `stock_zt_pool_em()` — 涨停板池（核心数据）
  - ✅ `stock_zt_pool_strong_em()` — 强势股池
  - ❌ `stock_zh_a_spot_em()` — 全 A 股行情（走 push2，不可用）
  - 个股行情降级走腾讯 API（`qt.gtimg.cn`）；历史K线走腾讯 ifzq（`-sL` 跟随重定向）或 BaoStock（免费，无需 key）。
- 大盘情绪模块已内置 Tencent API 降级方案（`qt.gtimg.cn`），TUN 模式下自动回退到指数级别数据。
- 字段映射、代理详情、覆盖率限制见 `references/data_sources.md`。
