# 游资战法 — 涨停板全景分析

基于 AkShare 提供完整的游资数据分析能力，覆盖：涨停板连板梯队、封板质量、板块热度、大盘情绪、游资情绪周期判断。

## 触发方式

用户提到以下关键词时自动触发：
- "游资"、"游资战法"、"打板"、"涨停"、"连板"
- "今天哪些涨停"、"涨停板分析"、"短线情绪"
- "情绪周期"、"今天能打板吗"、"明天买什么"
- "异动上榜"、"市场情绪"、"涨停复盘"
- "板块轮动"、"今天什么板块热"、"板块切换"（触发 --rotation）
- "封测"、"半导体涨停"、"哪个板块涨停最多"（触发板块热度分析）
- "连板高度"、"最高板"、"龙头是谁"（触发连板梯队分析）

### ⚠️ 涨停板数据的盲区

本技能所有分析模块**只统计封死涨停板的股票**。部分板块可能涨幅强劲（板块平均+2~5%、龙头+7~8%）但**零涨停**，这类板块在本技能的报告里完全不可见。

**典型案例：** 煤炭板块在2026-06-08整体走强（中国神华+4.72%、大有能源+7.62%），但0只涨停，涨停板池完全扫不到。

**什么时候需要考虑非涨停板板块：**
- 用户问"今天什么板块热"、"有没有其他板块"、"还有什么可以看的" → 必须同时做涨停板扫描 + 非涨停板板块趋势扫描
- 用户问具体的板块名称（如"煤炭怎么样"）→ 按板块名称直接扫成分股
- 单日涨停数 < 60只时 → 市场情绪偏弱，热点可能集中在非涨停板趋势方向上

### 1️⃣ 连板梯队
按连板数从高到低排列，标记每只股票的：
- 封单资金（亿）
- 是否炸板
- ⭐ 优质板标记（早盘秒封 + 封单>1亿）

### 2️⃣ 封板质量
- 集合竞价封板数/比例
- 早盘封板数/比例
- 午盘后封板数/比例
- 炸板数/炸板率
- 封单资金TOP10

### 3️⃣ 板块热度
按板块涨停家数排名，展示：
- 涨停家数
- 最高连板
- 具体个股列表

### 4️⃣ 大盘情绪
- 涨跌家数、涨跌比
- 涨停/跌停数量
- 全A成交额

### 5️⃣ 情绪周期判断 ⭐
多维评分体系自动判断当前游资情绪处于哪个阶段：
- 🔥🔥🔥 沸点区 — 情绪亢奋，分歧随时来临
- 🔥 回暖区 — 情绪好转，可参与
- 🌤 震荡区 — 情绪中性
- 🌧 冰点区 — 情绪低迷，多看少动

判断依据：涨停数 + 连板高度 + 封板率 + 竞价封板比例

### 6️⃣ 板块轮动追踪 ⭐（`--rotation`）
对比最近 N 个交易日，自动识别：
- 🔥 **持续热点** — 连续多天热度的板块
- 🌱 **新冒头板块** — 今日才爆发的方向
- ❄️ **退潮板块** — 热度消退的方向
- 🧭 **轮动方向** — 资金在板块间的流动方向

每日展示板块 TOP5 涨停家数，一目了然看清轮动节奏。

### 7️⃣ 打板标的选择 ⭐（资金适配）

> 完整的工作流见 `references/deep-sector-analysis.md`（含封单质量比计算、均线形态判断、资金配适步骤）。

当用户问"能打板的标的有哪些"或类似问题时，必须：

**① 查用户可用资金（从 portfolio.json 读取真实数据）**
- 运行 `portfolio_manager.py --check` 获取当前持仓 + 可用现金
- 如果 `portfolio.json` 为空且用户刚在本 session 中口述过持仓 → **立即写入**（见 stock-triage skill 的「持仓数据持久化铁律」）
- 如果 `portfolio.json` 为空且用户未口述过 → 问用户当前持仓

**② 筛掉买不起的标的**
- 对每个涨停股计算 **1手成本 = 现价 × 100**
- 排除 1手成本 > 可用资金 的标的
- 按资金体量标签：✅ 买得起 / ⚠️ 稍贵 / ❌ 超预算

**③ 封单资金质量分级**
- 封单/流通市值比 > 3% → 强封 ✅
- 封单/流通市值比 1%~3% → 中等
- 封单/流通市值比 < 1% → 弱封，容易炸板

**④ 打板推荐必须包含的信息**
```
标的 | 现价 | 1手成本 | 封单(亿) | 连板 | 板块逻辑 | 操作建议 | 建议仓位
```

每个标的还必须附：公告质检状态、买入区间、最高追价、止损、目标、持有周期，
以及 `A股T+1：当日买入不可卖出，最早可卖交易日`。公告扫描缺失或出现澄清/
异常波动/监管硬风险时，只能关注或回避。

**⑤ 操作建议分类**
| 情况 | 建议 |
|------|------|
| 已封死，封单强 | 排板等炸板回封，或明早竞价看1进2 |
| 已封死，封单弱 | 不追，炸板率高 |
| 盘中未封 | 观察板块热度，急拉不打板 |
| 竞价阶段 | 看竞价量能和价格 |

### 8️⃣ 情绪周期交叉验证

竞价封板率与炸板率需结合分析：
- 竞价封板率 > 80% + 炸板率 > 35% → 隔夜情绪极强但日内分歧大，警惕炸板潮
- 竞价封板率 < 30% + 炸板率 < 20% → 隔夜弱但封得稳，可能是趋势板
- 最高板 < 4板 + 涨停数 > 50 → 宽度好但高度不够，轮动快

### 🔟 板块趋势扫描（非涨停板方向）⭐

当用户问"今天什么板块热"且涨停数偏少（<60只），或用户表现出对趋势风格（非打板）的兴趣时，必须执行非涨停板的板块扫描。

**场景：** 2026-06-08煤炭板块走强但0涨停，涨停板池完全不可见。原因是机构/大资金驱动的板块行情——不靠封板，靠趋势。

**扫描方法（两步走）：**

**第一步：圈定候选板块**

从这些线索中找：
- 涨停板池中板块热度排名的邻居板块（同产业链上下游）
- 历史轮动数据中曾经热过的板块（如06/01煤炭9家涨停）
- 当日宏观/政策/商品异动（如期货大涨、夏季用电高峰、煤价上涨等）
- 大市值龙头异动（如当天中国神华+4.72%是明显的板块信号）

**第二步：拉成分股批量扫描**

对候选板块手动列出核心成分股（15~25家），用腾讯API批量查：

```python
import os, urllib.request
os.environ["NO_PROXY"] = ".gtimg.cn"

codes = ",".join(["sh601088","sh601225","sh600403",...])  # 板块成分股
url = f'http://qt.gtimg.cn/q={codes}'
req = urllib.request.Request(url, headers={'User-Agent': 'Mozilla/5.0'})
with urllib.request.urlopen(req, timeout=10) as resp:
    raw = resp.read().decode('gbk', errors='ignore')

results = []
for line in raw.strip().split(';'):
    val = line.split('=',1)[1].strip().strip('"').split('~')
    name, price, chg_pct, amt_yi, pe, total_mcap = \
        val[1], float(val[3]), float(val[32]), float(val[37])/10000, val[39], float(val[45])
    results.append((name, price, chg_pct, amt_yi, pe, total_mcap))
```

板块评估指标：
- **上涨比例** > 50% → 板块效应强
- **平均涨幅** > 1.5% → 资金流入明显
- **板块总成交** > 50亿 → 有机构参与
- **龙头涨幅** > 5% → 有带头大哥

详见 `references/non-zt-sector-scanning.md`。

## 🔬 打板理论基础框架（v2 — 反身性+特殊买家）

### 为什么打板能赚钱？

打板的根本原理不是技术分析，而是**反身性自反馈循环**（索罗斯, 1987）：

```
一只股票涨停 → 出现在涨停列表 → 游资/散户看到 → 更多人关注
    ↓                                                     |
这只票变成"板块龙头" → 媒体报道 → FOMO情绪               |
    ↓                                                     |
更多资金追进来 → 继续涨停                                  |
    ↓                                                     |
股价上涨 → 公司"看起来更值钱" → 基本面被重新定价           |
    ↓                                                     |
......直到没有人接盘 → 踩踏下跌                           |
    └─────────────────────────────────────────────────────┘
     自反馈循环：价格改变认知，认知改变价格
```

**打板选手的盈利来源：** 在正反馈循环的早期（首板/2板）上车，在负反馈开始（炸板潮/放量不涨）前下车。赚的不是公司价值，是**反馈惯性**的钱。

### 三层打板筛选模型

```
第一层：全量扫描 → 找出"资金在打的板块"
  工具：sector_scan.py（涨停聚合）+ hot-money-tactics --rotation（轮动）
  指标：涨停数 × 出现天数 × 连板高度 = 热度分
  理论：动量策略（Jegadeesh & Titman 1993）——过去强者未来继续强
  输出：热度分矩阵 + 持续/新冒头/退潮板块标注

第二层：板块内选股 → 筛出具体标的
  过滤器：
    ├─ ✅ 多头排列（MA5>MA10>MA20>MA60）
    ├─ ✅ 封单质量（封单/流通市值比）
    ├─ ✅ PE合理（非亏损，非泡沫估值）
    └─ ✅ 1手价格 ≤ 用户可用资金
  排除器（禁入条件，来自 stock-triage AGENTS.md）：
    ├─ 🚫 空头排列
    ├─ 🚫 净利润同比下降 > 10%
    ├─ 🚫 PE为负（亏损股）
    ├─ 🚫 布林跌破下轨（"加速下跌中，等待企稳"）
    └─ 🚫 RSI超卖 + 空头排列（"下跌中继非洗盘"）

第三层：竞价确认 → 决定是否进场
  关键时点：9:25竞价出价 → 9:35开盘确认（非9:30，等5分钟消化脉冲）
  判断逻辑：
    ├─ 小高开 0~3% → ✅ 最佳击球区，上车
    ├─ 高开 3~5% → ⚠️ 偏强，等回踩再考虑
    ├─ 高开 >5% → ❌ 太猛了，放弃
    └─ 平开/低开 → ❌ 转弱，放弃
```

### 反身性全维度检查（v2）

传统反身性模型假设资金同质化——这忽略了A股市场上**不同类型的买家**对反身性的影响完全不同：

```
              影响方式          反身性贡献      可预测性
───────────────────────────────────────────────────────
游资（传统）   慢慢吸→硬拉→派发   中（有席位背书）  高
量化（机器）   秒抢→秒撤→竞价砸   高（加速反馈）    低
散户（跟风）   看到涨停才追       高（FOMO燃料）    中
机构（大资金）  基本面驱动         低（打断反馈）    高
大股东/潜伏盘  解套就卖           负向（打断反馈）   中
```

#### ① 量化——反身性的加速器与扭曲器

```
传统反身性：   涨→人看到→人买→涨（小时级）
量化反身性：   涨→算法检测到→AI抢买→涨更快→AI止盈→闪崩（秒级）

量化在打板中的典型操作：
  涨停前300ms：算法检测到买盘加速 → 抢板
  封板瞬间：大单堵门 → 2秒内撤单留板（制造假封单）
  第二天竞价：高开 → 第一时间砸盘出货
```

量化对打板的影响：
- **加速繁荣期** — 以前游资拉板要半小时，量化3秒封死
- **制造假信号** — 量化抢的涨停没有"市场共识"，第二天常低开
- **炸板率上升** — 量化撤单极快，封单看起来大但下一秒可能全撤
- **判断量化参与度：** 秒封（<30秒）→ 量化概率高 | 撤单率 > 30% → 量化制造假封单 | 第二天竞价量异常大 → 量化砸盘概率高

#### ② 游资——反身性的启动器

游资与量化本质区别：游资有**席位背书效应**。知名游资席位买入 → 散户跟风 → 反身性形成。量化没有这个效应（没人跟算法代码买）。

**游资参与度判断：** 封板时间 > 30分钟（非秒封）→ 游资主导 | 封单稳定 > 10分钟不撤 → 真游资 | 低开高走涨停板 → 典型游资洗盘手法

#### ③ 大机构/大股东——反身性的打断器

无论多少游资和散户在买，一个大股东减持公告或机构大宗卖出，直接切断反馈循环。

**机构风险检查：** 近期是否有减持公告？本月是否有大宗交易？大股东质押比例是否过高？

#### ④ 潜伏盘——反身性的反向力量

涨停→老股东解套→卖出→封单被吃→反身性循环还没开始就结束。

#### 反身性综合判断流程

```python
def assess_reflexivity(stock_data):
    score = 0
    
    # 1. 反馈方向
    if 板块热度加速上升: score += 2
    elif 板块热度趋平: score += 1
    elif 板块热度下降: score -= 2
    
    # 2. 特殊买家判断
    if 封板时间 < 30秒: score -= 1  # 量化参与高，反馈不可靠
    if 游资席位可见且稳定: score += 2
    if 近期有大股东减持: score -= 3  # 直接打断反馈
    if 炸板率 > 40%: score -= 1     # 反馈衰竭信号
    
    # 3. 催化支撑
    if 有强政策/行业催化: score += 2
    if 无催化仅资金驱动: score -= 1
    
    # 结论
    if score >= 3: "强反身性，可参与"
    elif score >= 1: "中等，控制仓位"
    else: "弱反身性，不追板"
```

### 涨停分时形态分类

| 形态 | 特征 | 判断 |
|:----|:-----|:-----|
| **低开高走板** | 开-2~-5%→拉涨停 | 游资洗盘，强势 ✅ |
| **秒封板** | 开盘30秒内封死 | 量化+游资合力，但量化撤单风险 ⚠️ |
| **烂板** | 涨停后反复开合 | 分歧大，封板率低 ❌ |
| **尾盘板** | 14:30后拉涨停 | 手法猥琐，第二天低开概率高 ❌ |
| **一字板** | 开盘就封死 | 买不到，买到就是坑 ❌ |
| **趋势板** | 沿MA5/MA10稳步上行中涨停 | 主力控盘，有一定持续性 ✅ |

- 本机 ClashX TUN 模式下 `push2.eastmoney.com` 不可达，个股行情走腾讯 API 降级（详见 `references/data_sources.md`）
- 历史K线数据：腾讯 ifzq（`-sL` 跟随重定向）可用，BaoStock（免费，无需key）可用
- ⚠️ **ClashX TUN 模式**会阻断开往 `push2.eastmoney.com` 的流量（DNS 被解析为假 IP `198.18.x.x`），但以下 AkShare 接口已验证可绕过：
  - ✅ `stock_zt_pool_em()` — 涨停板池（核心数据）
  - ✅ `stock_zt_pool_strong_em()` — 强势股池
  - ❌ `stock_zh_a_spot_em()` — 全A股行情（走 push2）
- 大盘情绪模块已内置 **Tencent API 降级方案**（`qt.gtimg.cn`），TUN 模式下自动回退到指数级别数据
- `--rotation` 模式依次请求近 N 个交易日数据，耗时较长（每个交易日一个API调用）
