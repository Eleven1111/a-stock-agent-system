# 资金流向替代方案：从新闻中提取

## 背景

TUN 模式下 `push2.eastmoney.com` 和 `push2his.eastmoney.com` 被完全封锁，导致：
- `ak.stock_individual_fund_flow()` 不可用（走 push2his）
- 东财 datacenter API 报表权限不足
- 新浪/10jqka 资金流向页反爬

## 替代方案：SerpAPI 新闻资金信号提取

使用 SerpAPI `engine=google_news` 搜索个股/板块新闻，从新闻标题和摘要中正则提取资金流向关键词。

### 实现位置

`~/.hermes/skills/stock-analyst/scripts/news.py` 中的 `extract_fund_flow()` 函数。

### 支持的匹配模式

| 模式 | 示例匹配 | 输出 |
|------|----------|------|
| `主力/机构/北向资金净卖出X亿` | "主力资金净卖出13.95亿元" | `主力 卖出 13.95亿` |
| `净买入/净卖出X亿` | "机构净卖出311.85万元" | `资金 卖出 311.85万` |
| `融资加仓/减仓X` | "融资资金大幅加仓2股" | `融资 买入 2` |
| `北向资金净流入X亿` | "北向资金净流入5.23亿元" | `北向 买入 5.23亿` |

### 局限性

- 依赖新闻媒体是否报道，小金额/日常买卖不会被覆盖
- 新闻有延迟（几小时到1天）
- 金额单位不统一（亿/万需要正则区分）
- 仅能提取大额信号，不是完整资金流
